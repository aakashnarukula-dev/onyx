# Onyx Implementation Plan

> **Scope change (owner, 2026-10-11):** Onyx is plain terminals grouped in one window, each
> starting Claude in auto mode — nothing else. The accounts chip (§6), same-repo safety /
> `onyx-pane` (§7) and the pane system prompt were built and then removed. Panes use the
> user's own shell, environment and logins exactly like Terminal.app. Sections 6–7 are kept
> for history only.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Native pitch-black macOS terminal app tiling up to 6 Claude-in-auto-mode terminals per window, with per-pane GitHub/Vercel accounts and same-repo safety.

**Architecture:** One SwiftPM package. `OnyxCore` (library, no AppKit) holds all testable logic: layout math, env building, account parsing, pane registry, repo lock, `onyx-pane` commands. `Onyx` (AppKit executable) is a thin UI over SwiftTerm. `onyx-pane` (executable) is a thin CLI over `OnyxCore`. `scripts/bundle.sh` packs both executables into `Onyx.app`.

**Tech Stack:** Swift 6, AppKit, SwiftTerm `1.20.0` (exact), XCTest, Security.framework, `gh`, `git`, `vercel` CLIs.

**Spec:** `docs/specs/2026-10-11-onyx-design.md`

## Global Constraints

- macOS 14+ deployment target; arm64.
- No SwiftUI anywhere (CLT lacks its macro plugin). No swift-testing; XCTest only.
- All builds/tests go through `scripts/env.sh` (pins `SDKROOT=/Library/Developer/CommandLineTools/SDKs/MacOSX26.5.sdk`); run tests with `scripts/test.sh`.
- Colors: background `#000000`, foreground `#d4d4d4`, cursor `#ffffff`, focused border 1 pt `#2a2a2a`, unfocused border `#111111`, dividers `#1a1a1a`. No animations.
- Font SF Mono 13 default (`NSFont.monospacedSystemFont`).
- Max 6 panes per window. Min pane 200×120 pt. Window min size 640×400.
- Pane cwd `~/Developer`. Pane command exactly: `/bin/zsh -l -i -c 'claude --permission-mode auto --append-system-prompt-file <promptPath>; exec /bin/zsh -l -i'`.
- Support dir: `$ONYX_HOME` if set, else `~/Library/Application Support/Onyx`. Subdirs `panes/`, `locks/`. Files `settings.json`, `pane-prompt.md`.
- Secrets (Vercel tokens) only in Keychain, service `com.onyx.vercel`, account = label.
- Commits in this repo: author `aakashnarukula-dev <aakashnarukula.dev@gmail.com>` (already set in local git config).

## Review Focus

1. **App crash / force-quit leaves stale registry entries** — next `claim` must treat them as dead (pid file's pid not alive) and not force a worktree. Test in Task 3.
2. **Repo with no `origin` remote** — `push` must not hang or crash; prints `NO_REMOTE` and exits 2. Test in Task 4.
3. **Closing a middle pane** (e.g. pane 2 of 5) — remaining panes keep relative order and re-flow to `[2,2]`. Test in Task 1 (`GridLayout.frames` ordering) + manual in Task 7.
4. **Lock left by a killed push** — next push steals it when holder pid is dead instead of waiting 5 min. Test in Task 3.
5. **`gh` not logged in / token command fails** — env omits `GH_TOKEN`, pane still opens. Test in Task 5.

### Task 3: PaneRegistry + RepoLock

**Files:**
- Create: `Sources/OnyxCore/Paths.swift`, `Sources/OnyxCore/PaneRegistry.swift`, `Sources/OnyxCore/RepoLock.swift`
- Test: `Tests/OnyxCoreTests/PaneRegistryTests.swift`, `Tests/OnyxCoreTests/RepoLockTests.swift`

**Interfaces:**
- Produces:
  - `public struct OnyxPaths { public let home: URL; public init(env: [String:String] = ProcessInfo.processInfo.environment); public var panes: URL; public var locks: URL; public var settings: URL; public var prompt: URL }`
  - `public struct PaneClaim: Codable, Equatable { public var paneId: String; public var repoRoot: String; public var worktree: String?; public var branch: String; public var task: String; public var updatedAt: Date }`
  - `public struct PaneRegistry { public init(paths: OnyxPaths, isAlive: @escaping (Int32) -> Bool = { kill($0, 0) == 0 }); public func markAlive(paneId: String, pid: Int32) throws; public func markClosed(paneId: String); public func save(_ c: PaneClaim) throws; public func remove(paneId: String); public func live() -> [PaneClaim] }`
  - Liveness: app writes `panes/<id>.pid` (shell pid) via `markAlive`, deletes all pane files via `markClosed`. Claims live in `panes/<id>.json`. `live()` returns claims whose pid file exists and pid is alive; prunes the rest (deletes both files).

Steal if holder pid dead. Throws `OnyxError.lockTimeout`.
  - `public enum OnyxError: Error, Equatable { case lockTimeout, notARepo(String), git(String) }`

### Task 4: onyx-pane commands

**Files:**
- Create: `Sources/OnyxCore/Git.swift`, `Sources/OnyxCore/PaneCommands.swift`
- Modify: `Sources/onyx-pane/main.swift`
- Test: `Tests/OnyxCoreTests/PaneCommandsTests.swift`

**Interfaces:**
- Consumes: `OnyxPaths`, `PaneRegistry`, `PaneClaim`, `RepoLock`, `OnyxError` (Task 3).
- Produces:
  - `public struct Git { public static func run(_ args: [String], in dir: String) throws -> String }` — runs `/usr/bin/git`, returns trimmed stdout, throws `OnyxError.git(stderr)` on non-zero.
  - `public struct PaneCommands { public init(paneId: String, registry: PaneRegistry, paths: OnyxPaths); public func claim(dir: String, task: String) throws -> String; public func who(dir: String) throws -> String; public func push() throws -> (output: String, exitCode: Int32); public func release() throws -> String }`
- Output contract (first token is machine-readable, one line each):
  - claim → `OK <repoRoot>` or `USE_WORKTREE <path> <branch>`. Worktree when another live pane's claim has same `repoRoot` and `worktree == nil`. Path `<repoRoot>/.onyx-worktrees/<first 8 of paneId>`, branch `onyx/<first 8 of paneId>`, base = current HEAD of main checkout; append `.onyx-worktrees/` to `.git/info/exclude` once. Re-claim by same pane updates task, keeps its worktree.
  - who → one line per live pane: `<paneId8> <branch> <worktree or "main"> <task>`.
  - push → under `RepoLock`: if no `origin` → `NO_REMOTE`, exit 2. Else target = `origin/HEAD` branch (fallback `main`); `git fetch origin`; `git rebase origin/<target>` in the pane's checkout; on failure → `git rebase --abort` is NOT run (Claude resolves in place), print `CONFLICT <files from git diff --name-only --diff-filter=U>` exit 1. On success: in a worktree push `HEAD:refs/heads/<target>`; in the main checkout push current branch. Print `PUSHED <short sha>` exit 0. Lock always released.
  - release → removes claim; if worktree and its branch is merged into `origin/<target>` (or no remote: into local target), `git worktree remove` + `git branch -d`, print `RELEASED removed-worktree`; unmerged → `RELEASED kept-worktree <path>`.
- `main.swift`: parse `claim <dir> <task...>`, `who [dir]`, `push`, `release`; `paneId` from `ONYX_PANE_ID` (missing → print `ERROR not in an Onyx pane` exit 3); errors print `ERROR <message>` exit 3.
